# Fellow 0 - 你的笔名

> 本文档为「开源人文学者」第一期的成员仓库模板。使用「Use this template」建出自己的仓库，删掉本行，并把标题中的「你的笔名」换成你的笔名。

## 仓库简介

**一个自身最为关切的人文问题**，以及这个问题在你这里是怎么被问出来、怎么被改写的。

- 问题始终为最新表述（可直接改写，旧版全量储存于 git 历史）。
- 只增不删：每一次改写在 Change Log 里留一行，带日期。

- 问题本体：根目录 [question.md](question.md)
- 问题更新：[distill.md](distill.md)
- 操作：[guide.md](guide.md)

## 体例硬规则

1. 本仓库只记**一个问题的表述史**：以思想史角度记录问题本体及 Change Log。
2. Change Log 只增不删、最新在上；**每月重读**，无变化则记录「YYYY-MM：重读，无变化」。

## 研究声明

请在建仓时读完这四条。它们不会从这个 README 里删掉。

1. 本仓库的公开内容以 **CC0 1.0** 发布（见 [LICENSE](LICENSE)），任何人可以任何目的使用，无需署名。
2. 这些内容**可能被用作研究材料**，方向涉及思想史、HCI、社会学。
3. git 历史即时间戳数据。改写之后，旧版本仍在历史里。
